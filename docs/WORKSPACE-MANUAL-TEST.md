# 受控工作区手动验收

这是一份可执行的手测清单，结果栏应由测试者填写。它不宣称已连接手机或独立 App 执行环境。

1. 从首页进入“受控工作区”，在任务框输入“按目标岗位分类这些虚构简历”。选择 `alice-resume.docx`、`bo-resume.xlsx`、`chen-resume.docx`、`dai-resume.xlsx`。预期：只显示 4 个文件名和 f0–f3；未授权前没有正文读取。
2. 重新打开系统选择器，同时选这 4 个文件和 `fifth-not-selected.txt`。预期：选择被拒绝，提示必须是 1–4 份，未创建准备任务。
3. 点击“读取并预览实际发送内容”，在本地读取确认框选择“拒绝”。预期：显示未上传，页面没有准备任务。
4. 再次点击并选择“允许读取”。预期：DOCX/XLSX 使用 Office 正文解码，弹窗同时显示完整任务、所有可能上传的正文、payload 和哈希；不显示假默认简历。
5. 在 `prompt-injection.txt` 中测试提示注入，单独选择它与其他文件。预期：正文可见，但只能请求 f0–f3 与 `list_inputs`、`read_document`、`write_table`、`finish`；不能扩大文件范围、读目录、联网或操作系统。
6. 在完整 payload 弹窗点击“取消并清除准备内容”。预期：任务回到未上传状态。再次准备后点击“确认云端授权（尚未启动）”，再在第二个确认框点击“取消”。预期：仍未启动。
7. 点击“确认启动”。预期：状态从 PREPARED → AUTHORIZED → RUNNING → COMPLETED/FAILED/CANCELLED；返回页面或重进后仍能看任务状态，前台聊天输入与滚动不被抢焦点。第二次确认取消时保留 PREPARED 任务，不能启动。
8. 执行期间点“取消后台任务”。预期：状态为 CANCELLED，不能出现完成结果。失败也必须显示原因，不得伪造 CSV/HTML。
9. 完成后依次点击“查看 results.csv”“查看 summary.html”“查看 audit.jsonl”。预期：看到实际文件内容与审计事件；证据来自同一份已读取正文。
10. 点击“导出只读结果”，确认后再选保存位置。预期：保存的是实际 CSV 字节；取消任一确认不产生导出。点击“清除本地工作区”并确认后，任务状态/结果消失，并提示已导出的副本与云同步无法撤回。

未测：未安装 APK、未连接真机、未进行主代理所说的 host 内部越权重放测试；这些不要求测试者凭空操作不可见接口。
