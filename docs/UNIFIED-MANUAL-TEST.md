# 统一工作区手机手测

以下步骤用于真实 Android 设备，样例资料均为虚构或公开测试素材。

1. 从系统选择器选择 `samples/unified` 目录，授予持久读权限；确认递归列表显示 txt、md、csv、Office、PNG、重复文件和损坏文件，资源 ID 不显示 URI。
2. 单独选择 `samples/unified/readme.txt`，确认只能看到该文件，不能通过 `../` 或猜测 sibling ID 读取目录其它项目。
   单文件 provider 不支持安全改名；如需改名，请选择包含该文件的目录并在目录授权范围内操作。
3. 选择可写目录，创建文本文件，修改并刷新；确认原位置内容改变。尝试编辑 Office、图片，确认被拒绝。
4. 对虚构票据 PNG 执行 OCR 任务，确认结果写入成果根；对损坏 PNG/Office 显示真实失败原因。
5. 运行短信提取任务，确认输入是应用内副本，所有选中短信最终只生成一个汇总 CSV；任务期间返回前台，确认可继续查看进度。
6. 在工作区执行改名、复制、移动和删除；删除后打开回收列表，恢复到原位置；目标占用时确认使用 `.restored-N`，不覆盖现有文件。
7. 在系统设置撤销目录读权限，再刷新、stat、read、write、delete；每项都应失败并显示对应的授权/能力错误。撤销单文件授权后同样检查。
8. 开始递归任务后取消，或杀掉进程模拟中断；确认没有自动重放或假 rollback，未完成备份保留在回收区。
9. 使用前台输入完成一次统一任务，确认任务结束后输出可在成果根查看，外部文件仅在用户授权范围内变化。
