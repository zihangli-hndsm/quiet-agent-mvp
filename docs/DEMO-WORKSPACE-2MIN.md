# 受控工作区两分钟演示

**0:00–0:25**　进入“受控工作区”，输入“按目标岗位分类这些虚构简历”，选择 `samples/workspace/` 的四份 Office 文件。指出第五份和提示注入文件不在本次范围。

**0:25–0:55**　点击读取，明确这是本地敏感内容授权。展示使用 OfficeText 解码后的文件正文、任务、完整 payload 与哈希；说明账号云同步风险，以及未来 App 执行环境仍未实现、不能登录。

**0:55–1:10**　关闭预览，再次准备。先点“确认云端授权（尚未启动）”，展示第二个独立的启动确认；确认后才启动后台 Service。

**1:10–1:40**　切回聊天应用输入和滚动，说明执行不会抢屏；回到页面查看 PREPARED/AUTHORIZED/RUNNING/COMPLETED（或失败/取消）状态与可重进结果。

**1:40–2:00**　打开实际 CSV、HTML、审计记录，说明导出是保存实际 CSV 文件且需要再次确认；最后展示取消和清除提醒：外部上传、云同步与已导出副本无法撤回。
