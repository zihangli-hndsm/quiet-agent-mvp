# 统一工作区

统一工作区把用户在系统文件选择器中选入的目录或文件注册为持久授权资源。目录按原位置递归读取，文件保留单文件范围；任务刷新时重新读取当前内容。模型只看到稳定的 `root-id:relative-path` 资源 ID，不会看到 SAF URI。

用户明确选择可写授权后，支持在原位置编辑限定文本文件（`.txt`、`.md`、`.csv`、`.html`）；Office、图片和其它二进制文件只读。短信或其它一次性文本通过 `importText` 写入应用成果目录副本，不获得短信来源的持续写权限。

成果根始终存在于应用私有目录。覆盖、删除和复制目标前会把旧内容同步到私有 control 回收区并记录 hash；可通过回收列表恢复，目标冲突自动增加后缀。移动在复制后验证 hash，失败时保留源文件。操作 journal 只记录阶段与 root 标识，不记录正文。
