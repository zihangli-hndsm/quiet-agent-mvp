# Quiet Agent v0.2.1 演示脚本（约 3 分钟）

## 演示前

- 用 USB 安装 Release 页的 v0.2 演示 APK；手机无需联网。
- 把 `tests/receipt_fixtures` 生成的 12 张“虚构数据”票据复制到手机本地。
- 准备一个普通聊天或记事应用，用来证明用户仍能持续输入。

## 现场流程

**0:00—0:30｜先说明边界**

打开 Quiet Agent。指出它没有联网权限，也没有相册全库权限。选择照片前，页面先告知票据可能包含姓名、账号、地址等敏感信息；本次只允许读取用户选中的照片、本地 OCR、去重和生成资料包。

**0:30—1:05｜选择并逐次授权**

选择 12 张虚构票据，其中包含 8 张清晰票据、2 张完全重复图片、1 张金额模糊图片和 1 张非票据。系统选择器返回后，展示本次范围、目的、允许操作和导出风险。点击“授权并开始”。强调系统授予文件读取能力仍不代表任务获得授权；每次任务都要单独确认，修改范围会让旧授权失效。

**1:05—1:50｜同机并行**

任务进入后台后，立即切到聊天或记事应用，连续输入一段文字并滚动页面。输入焦点、键盘和画面始终属于用户；Quiet Agent 不启动界面、不模拟触摸、不调用输入法，只用后台线程串行完成离线 OCR 与归档。

**1:50—2:25｜查看真实结果**

返回 Quiet Agent。展示识别数量、去重数量、自动计入的人民币总额和待核对数量。打开报告，回看每张票据的商户、日期、金额以及证据位置；金额模糊和非票据保留在报告中，但不进入合计。展示 ZIP 内只有去重后的图片，并含 CSV、HTML、清单和审计快照。

**2:25—3:00｜安全收尾**

打开审计记录，展示告知版本、任务规格摘要、授权时间、输入哈希、阶段事件和输出哈希；日志不保存 OCR 原文。点击导出，应用再次提示敏感信息风险，确认后才打开系统分享面板。说明审计是可核对的执行凭证，不宣称第三方认证或不可篡改。最后展示“清除此任务本地数据”。

## 建议讲给投资人的一句话

Quiet Agent 把“手机上的 Codex”拆成两个平面：用户独占交互平面，Agent 只在经过逐次授权的数据平面工作；结果可回看、失败不伪装完成、每一步留下可核对凭证。
